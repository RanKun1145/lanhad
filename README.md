# lanhad

用于 Plain Craft Launcher 2（PCL2）2.99.0.0 的游戏下载功能扩展工具。

## 功能

解除 PCL2 2.99.0.0 的游戏下载限制，其他功能和更新保持原样。

## 适用版本

- Plain Craft Launcher 2（PCL2）2.99.0.0

## 运行平台

- Windows 7
- Windows 8 / 8.1
- Windows 10
- Windows 11

## 使用方法

1. 打开 lanhad。
2. 将原版 PCL2 的 EXE 文件拖入软件窗口。
3. 点击“开始处理”。
4. 处理完成后，新的启动器会生成在原版启动器所在目录。
5. 打开新生成的启动器即可使用游戏下载功能。

建议提前备份原版文件。

## 常见问题

**Q：可以解除游戏下载限制吗？**

可以，适用于 PCL2 2.99.0.0。

**Q：原版的其他功能还在吗？**

本工具只针对游戏下载限制进行修改，其他功能原则上保持不变。

**Q：可以用于更新版本的 PCL2 吗？**

目前只适配 2.99.0.0。其他版本暂未测试，需要重新适配。

## 说明

本项目不提供、不包含 PCL2 软件本体，请自行获取原版程序。
